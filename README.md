# Chez Nounou Alison — site

## Voir le site sur ton ordinateur
1. Installer Node.js si besoin.
2. Ouvrir le dossier dans un terminal.
3. Lancer : `npm install`
4. Puis : `npm run dev`

## Mettre sur Vercel
Le plus simple est de déposer ce dossier dans un dépôt GitHub puis de l'importer dans Vercel.

## Ajouter une fiche
- Mets le PDF dans `public/fiches/recettes` ou `public/fiches/activites`.
- Ajoute une ligne dans le tableau `recipes` ou `activities` dans `src/main.jsx`.
